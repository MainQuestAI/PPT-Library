# Security Policy

## Supported Versions

The current source release is the supported version for security reports.

## Reporting a Vulnerability

Please report security issues through GitHub Security Advisories for `MainQuestAI/PPT-Library` when available. If advisories are unavailable, open a minimal issue that does not include exploit details, secrets, customer files, or private data.

## Data Safety

PPT Library is local-first. It may index private presentation material on a user's machine, but those files must not be committed to this repository.

Never include these in a public report or pull request:

- Real PPT files or screenshots.
- SQLite databases or generated HTML previews.
- `.env` files, API keys, tokens, private certificates, or passwords.
- Customer names, customer paths, private deal materials, or proprietary source decks.

Use synthetic demo decks generated by `scripts/create_demo_decks.py` when reproducing issues.
