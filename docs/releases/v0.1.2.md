# v0.1.2 Release Notes

Date: 2026-05-22
Status: AGENT DOCUMENTATION RELEASE

## Summary

`v0.1.2` 是 PPT Library 的文档与 Agent Skill 收口版本。该版本合并本地 `codex/ppt-library-skill-design` 分支，将完整中文 README、多 Agent Skill 说明和安装验证口径纳入 `main`。

## Included

- `pyproject.toml` 和 `uv.lock` 版本升至 `0.1.2`。
- README 改为完整中文入口，覆盖项目定位、能力边界、安装、Agent 调用、CLI、JSON 契约、QA、版本记录和常见问题。
- 新增 `skills/ppt-library/SKILL.md`，面向 Claude Code、Codex、Hermes、OpenCode、OpenClaw 等 Agent。
- 新增 `skills/ppt-library/references/agent-adapters.md`，说明多 Agent 安装目录、验证方式和适配契约。
- 新增 `skills/ppt-library/agents/openai.yaml`，提供 OpenAI/Codex 风格的展示元信息。

## Verification

发布前必须通过：

```bash
uv run --extra test pytest
uv run --extra lint ruff check .
uv run --extra lint mypy
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-smoke schema --output json
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-smoke status
uv run --extra test ppt-lib --version
```

当前基线：`154` 个自动化测试。

## Known Limits

- 本版本只收口文档和 Skill，不新增 CLI 行为。
- `assemble`、MCP Server 和 Web UI 仍不进入当前版本。
- Skill 安装到各 Agent 的本地目录仍需用户或宿主工具执行复制动作。
