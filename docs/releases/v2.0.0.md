# PPT Library v2.0.0 Release Notes

**Release Date:** 2026-06-24
**Previous Version:** v1.5.0
**Database Schema:** v5

---

## Summary

v2.0.0 completes the Wave B (Asset Intelligence + Workbench) and Wave C (Team Preview + Enterprise GA) iterations. PPT Library is now a local-first, agent-native, human-governed, team-capable PPT asset intelligence system.

---

## New Features

### v1.7 — Asset Intelligence & Lineage
- Asset/Revision/Lineage schema with 6 tables
- Layout and visual fingerprinting (normalized bounding boxes, media/font signals, slide-size aware)
- Near-duplicate classifier (multi-signal: text Jaccard + visual hash)
- Lineage inference and cycle detection (per-path DFS)
- Classification suggestion pipeline (deterministic keyword rules + review state)
- Feedback ranking v2 (Bayesian shrinkage + business ranking)
- Asset health detectors with finding lifecycle (detect → resolve → rescan, dedup on rescan)

### v1.8 — Local Review Workbench
- Application service layer (Search/Asset/Health/Review/Job/Library)
- FastAPI REST API (18 endpoints, standard envelope, RBAC on write endpoints)
- Workbench dashboard HTML shell (dark theme, responsive)
- Server-Sent Events for job progress and health updates
- Audit log for all write operations

### v1.9 — Team Preview
- Repository Protocol interfaces (SQLite implementation + Factory)
- RBAC (4 roles: viewer/editor/admin/owner, 16 permissions, workspace isolation)
- Connector SDK (Connector ABC, LocalFileSystemConnector, Registry, incremental sync)

### v2.0 — Enterprise GA
- Policy engine (PolicyAction/Effect/Confidentiality, DENY > APPROVAL > ALLOW)
- Multi-workspace isolation (workspace + membership + role access)
- Approval workflows (ReviewRequest + approve/reject/revoke)
- Analytics (query/asset/health/governance metrics)
- GA release gate (10 checks validating all enterprise features)

---

## Breaking Changes

- DB schema upgraded to v5. `init_db()` now creates identity/job/contract tables directly (CREATE IF NOT EXISTS, safe on existing v4 DBs).
- `ppt-lib capabilities` now reports schema 5 and enabled feature flags.
- Workbench requires `[workbench]` extra (fastapi, uvicorn, httpx2).

---

## CLI Additions

- `ppt-lib workbench start [--host] [--port]` — launch the workbench API server
- `ppt-lib workbench status` — probe server health

## Known Limitations

- Job Engine CLI (`jobs list/inspect/cancel`) not yet wired into main CLI
- Workbench frontend pages (search/asset/health detail views) not implemented
- Postgres backend, OIDC, and deployment tooling deferred to follow-up iterations
- Visual pHash/palette are placeholders (require rendered image pipeline)
