# v0.1.3 Release Notes

Date: 2026-05-23
Status: READY

## Summary

`v0.1.3` focuses on search quality measurement, safe library cleanup, and V2 assemble readiness.

## Included

- Search evaluation manifest and `eval-search` CLI.
- Threshold calibration report with `target_met` and per-query failure reasons.
- Safe `prune` command with dry-run protection, apply-time DB backup, and batch deletes.
- Assemble fidelity spike runner with timestamped report output.
- Specs and safe example manifests for local `.gstack/` workflows.

## Verification

```bash
uv run --extra test pytest
uv run --extra lint ruff check .
uv run --extra lint mypy
uv run --extra test ppt-lib --version
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-v013-smoke schema --output json
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-v013-smoke status
```

## Known Limits

- Production assemble remains outside this release.
- Real search manifests and spike reports stay under `.gstack/`.
- Search evaluation quality depends on user-maintained ground truth queries.
