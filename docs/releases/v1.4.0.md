# v1.4.0 Open-source Preview

Date: 2026-06-06

`v1.4.0` is the first open-source preview release focused on the PPT asset intelligence loop: key page identification, review-pack export, deal context, reuse tracking, and business-aware search results.

## Highlights

- Added `ppt-lib insights key-pages` to list reusable key page candidates.
- Added `ppt-lib insights review-pack` to export reviewable slide metadata for humans or agents.
- Extended `record-deal` with structured description fields while keeping old notes readable.
- Extended search JSON and HTML with `page_role`, `importance_score`, `importance_reason`, `needs_visual`, `reuse_count`, `won_count`, `lost_count`, and `win_rate`.
- Added a synthetic demo deck generator using the optional `demo` extra.
- Added open-source release checks and public snapshot guidance.

## Verification

- `uv run --extra test pytest`
- `uv run --extra lint ruff check .`
- `uv run --extra lint mypy`
- `uv build`
- `uv run python scripts/release_check.py --output json`

## Release Notes

- This release remains source-install first. PyPI publishing is planned later.
- Demo PPT files are generated locally and are not committed to the repository.
- The public release should be published through a clean snapshot, not by pushing private development history.
