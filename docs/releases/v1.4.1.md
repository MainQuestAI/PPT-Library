# v1.4.1 PaddleOCR MCP Recommended Stack

Date: 2026-06-10
Status: Release candidate

`v1.4.1` is a small hardening release that makes local embeddings plus PaddleOCR MCP the recommended implementation path for batch PPT slide recognition.

## Highlights

- Added `paddleocr_mcp` as a first-class vision provider.
- Added `setup --mode paddleocr-mcp`, which switches OCR/vision recognition while preserving the existing embedding provider.
- Added the optional `paddleocr` extra for installing `paddleocr-mcp`.
- Added `index --from-sources --file-workers N` for conservative PPTX file-level parallel indexing.
- Added a recommended implementation guide for local embeddings plus PaddleOCR MCP.
- Explicit PaddleOCR MCP failures now stop indexing instead of silently falling back to text extraction.

## Recommended Path

```bash
uv sync --extra test --extra lint --extra paddleocr
uv run ppt-lib setup --mode lmstudio
uv run ppt-lib setup --mode paddleocr-mcp
export PADDLEOCR_MCP_AISTUDIO_ACCESS_TOKEN="<your-token>"
uv run ppt-lib index --from-sources --file-workers 2
```

Start with `--file-workers 2`. Increase the worker count only after a small run confirms that the OCR endpoint and local SQLite writes are stable.

## Notes

- AI Studio quota and free allowance can change. Confirm the current page allowance in the AI Studio console before a large run.
- Tokens must stay outside `config.yml`.
- This release does not change the database schema.
