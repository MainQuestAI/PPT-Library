# PPT Library v1.5.0 Release Notes

**Release Date:** 2026-06-23
**Previous Version:** v1.4.1
**Database Schema:** v4 → v5

---

## Summary

v1.5.0 establishes the production foundation for PPT Library. This release introduces stable asset identity, a contract registry with machine-readable schemas, a job engine for resumable long-running tasks, incremental governance, and PPTX safety checks.

---

## New Features

### Contract Registry & Capabilities
- 7 JSON Schema contracts bundled (capabilities, search-request/response v2, deck-master-selection, asset-identity, feedback-event, job)
- `ppt-lib capabilities --output json` reports runtime capabilities from real environment
- `ppt-lib contract list/show/validate` for contract inspection and validation
- Stable error code system with 40+ predefined codes
- Envelope v2 builder for all machine output

### Stable Asset Identity
- Content fingerprinting for `slide_revision_id` and `deck_revision_id`
- Canonical/revision identity mapping with `asset_identity_map` table
- Identity registry export/import for cross-environment migration
- Schema v5 migration with backup/verify/restore

### Job Engine
- Full lifecycle: create → start → progress → complete/fail/cancel/retry
- Stage tracking with artifact paths
- Idempotency keys prevent duplicate jobs
- Event emission for job lifecycle monitoring
- Progress tracking with total/completed/failed units

### Incremental Governance
- Affected-scope detection for duplicate groups and deck families
- Manual override preservation (never auto-overwrite manual decisions)
- dry-run change summary before applying
- Consistency validation (orphan members, empty families)

### PPTX Safety
- Archive entry count and size limits
- Path traversal detection
- External relationship inventory
- Embedded object and VBA macro warnings
- Structured safety reports with error codes

---

## Breaking Changes

- Database schema upgraded from v4 to v5. Migration is available via `ppt_lib.migrations.apply_migration()`.
- 10 new database tables: asset_identity_map, deck_asset_identity, identity_overrides, contract_registry, migration_journal, jobs, job_stages, job_events, job_checkpoints, staged_assets.

## Compatibility

- macOS (arm64/x64): Tier-1
- Ubuntu LTS (x64): Tier-1
- Windows 11 (x64): Tier-2 (text-only mode without LibreOffice)

---

## Migration Guide

1. Backup your database: `cp ~/.ppt-library/index.db ~/.ppt-library/index.db.bak`
2. Run migration (future CLI command: `ppt-lib migrate apply`)
3. Verify: `ppt-lib doctor --output json`

---

## Test Baseline

- 653 automated tests (up from 534 in v1.4.1)
- 119 new tests added for contracts, capabilities, identity, migration, jobs, governance, and safety

---

## Known Limitations

- Job Engine CLI commands (`ppt-lib jobs list/inspect/cancel/resume/retry`) are not yet wired into the main CLI
- Incremental governance currently provides the framework; full integration with existing clustering and versioning logic is planned for follow-up releases
- Identity fingerprinting uses basic PPTX content hashing; perceptual hashing for near-duplicate detection is planned for v1.7
