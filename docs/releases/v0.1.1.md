# v0.1.1 Release Notes

Date: 2026-05-22
Status: RELEASE HARDENING

## Summary

`v0.1.1` 是 PPT Library V1.1 发布硬化版本，重点提升真实样本 QA 的可复跑性、本地模型链路韧性、diagnostics 可解释性和发布交接完整度。

## Included

- `pyproject.toml` 版本升至 `0.1.1`。
- 本地样本 QA 增加 `--fresh`，清理样本 QA home 中的生成状态，避免旧索引影响本轮结果。
- 样本报告补充 `fresh`、单样本耗时、状态原因、搜索质量基线字段。
- 搜索质量基线覆盖 `AI 智能体`、`数据治理`、`CMS 部署`、`SCRM`、`微信小店`、`营销自动化`。
- LM Studio vision 保持 `json_schema -> json_object` 回退。
- vision 文件读取异常进入文本 fallback 链，并写入 warning。
- diagnostics 输出 embedding、vision、fallback 三条链路状态。
- V2 assemble spike 文档准备完成。

## Verification

发布前必须通过：

```bash
uv run --extra test pytest
uv run --extra lint ruff check .
uv run --extra lint mypy
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-smoke schema --output json
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-smoke status
uv run --extra test ppt-lib --version
uv run python -m ppt_lib.sample_qa --phase baseline --max-files 6 --fresh
```

当前基线：`154` 个自动化测试。

本地样本 QA 证据：

- baseline fresh-run：6 个样本，49 页，`failed_job_count=0`，`skipped_embeddings=0`，6 类 query 均有结果。
- complex fresh-run：4 个样本，746 页，`failed_job_count=0`，`skipped_embeddings=0`，6 类 query 均有结果。
- `overall_status=warning` 已接受，原因是 LM Studio 格式回退、LibreOffice macOS stderr 噪音和搜索质量 off_target 标记；无阻断失败。

复杂样本压力轮：

```bash
uv run python -m ppt_lib.sample_qa --phase complex --vision-limit 1 --no-full --fresh
```

## Known Limits

- `assemble` 仍处于 V2 spike 准备阶段，未进入正式功能。
- Linux watch 行为仍需跨平台验证。
- 搜索质量基线目前记录偏题情况，暂不自动调参。
- 真实 PPT 样本路径和 QA 报告继续保留在 `.gstack/`。
