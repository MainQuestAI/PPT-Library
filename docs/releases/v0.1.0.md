# v0.1.0 Release Notes

Date: 2026-05-22
Status: RELEASE BASELINE

## Summary

`v0.1.0` 是 PPT Library V1 基线版本，目标是交付一个本地优先、Agent 可调用的 PPT 页级语义库 CLI。

## Included

- 13 个 V1 模块：配置、SQLite、embedding、截图、vision、diagnostics、discovery、watch、indexer、searcher、HTML review、CLI、sample QA。
- CLI 入口：`index`、`search`、`status`、`discover`、`watch`、`vision --test`、`schema`。
- 本地模型链路：LM Studio embedding、LM Studio vision、文本 fallback。
- 本地样本 QA：manifest 驱动，报告写入 `.gstack/qa-reports/`。
- CI 质量门禁：pytest、ruff、mypy、CLI schema smoke。
- 发布文档：README、依赖清单、发布检查清单。

## Verification

发布前必须通过：

```bash
uv run --extra test pytest
uv run --extra lint ruff check .
uv run --extra lint mypy
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-smoke schema --output json
uv run --extra test ppt-lib --home-dir /tmp/ppt-lib-smoke status
uv run --extra test ppt-lib --version
```

当前基线：`151` 个自动化测试。

## Known Limits

- `assemble`、AI 文案适配、MCP Server、Web UI 不进入 V1。
- 大规模近似向量索引暂不引入 sqlite-vec / hnswlib。
- 真实 PPT 样本路径只保存在 `.gstack/`，不进入仓库。
- Linux watch 行为仍需后续跨平台验证。
